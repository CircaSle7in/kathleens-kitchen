HOW TO USE THE GUIDES
---------------------
The guides are .html files — just double-click to open in your web browser
(Chrome, Safari, etc.). To save as PDF, press Ctrl+P (or Cmd+P on Mac)
and choose "Save as PDF."


HOW TO PRINT STICKERS
---------------------
1. Go to brand-assets page: https://kathleens.kitchen/brand-assets.html
2. Pick a sticker design
3. For round stickers: Buy Avery 22807 labels (2" diameter)
4. For rectangle labels: Buy Avery 5163 labels (2" x 4")
5. Print on any home inkjet or laser printer

For professional bulk stickers: StickerMule.com or StickerGiant.com


QR CODE PRINTING TIPS
---------------------
- Print at least 1 inch (2.5 cm) square
- Keep a white border around the code
- SVG files are for print (scale to any size)
- PNG files are for digital use (social media, email)
