How to Add a New Event

Each event on your site is a "card" — a block of code that describes the date, items, spots, and button. To add a new event, you copy an existing block and change the details.

Here's what to do:

  1. Open index.html and search for UPCOMING EVENTS (use Ctrl+F or Cmd+F).
  2. Scroll down until you see the event cards. Each one starts with a comment like <!-- EVENT 1: ... -->.
  3. Copy the entire template below and paste it right before the closing </div> that says <!-- end events-grid --> (or just after the last event card).
  4. Change the parts in ALL CAPS to your real event details.
Template — Copy This Whole Block
<!-- EVENT: YOUR EVENT NAME -->
<div class="event-card">
    <div class="event-card-header">
        <div class="event-date-badge">
            <span class="month">MAY</span>
            <span class="day">10</span>
        </div>
        <span class="event-status open">Open</span>
    </div>
    <div class="event-card-body">
        <h3 class="event-name">YOUR EVENT NAME</h3>
        <p class="event-desc">A short description of what this bake is about.</p>
        <div class="event-items-label">Available Items</div>
        <ul class="event-items">
            <li><span>Grandma's Rolls</span><span class="item-price">$10/dozen</span></li>
            <li><span>Cinnamon Rolls</span><span class="item-price">$18/dozen</span></li>
            <!-- Add or remove items as needed -->
        </ul>
        <div class="event-progress">
            <div class="event-progress-label">
                <span><strong>0</strong> of 20 spots claimed</span>
                <span>20 left</span>
            </div>
            <div class="event-progress-bar">
                <div class="event-progress-fill green" style="width: 0%"></div>
            </div>
        </div>
        <p class="event-order-by">Order by May 7, 2026</p>
        <a href="#order" class="btn btn-pink" onclick="selectEvent('your-event-id')">Order Now &mdash; 20 spots left</a>
    </div>
</div>

Things to change in the template:

→MAY and 10 — Change to your event's month and day.
→YOUR EVENT NAME — Something fun like "Mother's Day Brunch" or "Summer Bread Drop".
→The item list — Add or remove <li> lines for whatever you're baking.
→20 (the max orders) — Change to however many spots you want to offer.
→your-event-id — A short nickname with no spaces, like mothers-day-2026. This connects the card to the order form.
→Order by date — The deadline for people to order.
Don't forget the order form! When you add a new event, you also need to add it in two more places so the order form knows about it. Scroll down in index.html to find:

1. The event dropdown — Search for eventSelect. Add a new <option> line:
<option value="your-event-id">Your Event Name (May 10) — 20 spots left</option>

2. The checkbox group — Search for event-items-group. Copy one of the existing <div id="items-..."> blocks and change the id to match your event ID (like items-mothers-day-2026) and update the items inside.

3. The JavaScript name mapping — Search for eventNames near the bottom. Add a new line:
'your-event-id': "Your Event Name",
Updating the progress bar: As orders come in, update the numbers in the event card. Change the <strong>0</strong> of 20 text, the "20 left" text, the button text, and the width: 0% on the progress bar. For example, if 5 of 20 spots are taken, set width: 25%. The color works like this: green for under 70%, orange for 70-90%, and red for over 90%.

How to Mark an Event as Sold Out

When an event fills up, you need to make three small changes to that event's card:

Step 1: Find the event card's opening <div> tag. Change it from:

<div class="event-card">

To:

<div class="event-card is-sold-out">

Step 2: Find the status badge for that event. Change it from:

<span class="event-status open">Open</span>

To:

<span class="event-status sold-out">Sold Out</span>

Step 3: Find the "Order Now" button at the bottom of that event card. Change it from:

<a href="#order" class="btn btn-pink" onclick="selectEvent('...')">Order Now &mdash; 5 spots left</a>

To:

<span class="btn btn-sold-out">Sold Out</span>

Also update the progress bar to show all spots taken. Set the numbers to match (e.g., "12 of 12"), change "left" to "None left", and set the progress fill to width: 100% with the red class. Also remove this event from the dropdown list in the order form so nobody tries to order it.

How to Update Prices

Prices appear in three places throughout the file. You'll want to update all of them to keep things consistent.

Place 1: Event cards — Each event card has a list of items with prices. Search for the item name (like "Cinnamon Rolls") and you'll find lines like this:

<li><span>Cinnamon Rolls</span><span class="item-price">$18/dozen</span></li>

Change $18/dozen to your new price.

Place 2: Order form checkboxes — Search for event-items-group to find the order form sections. Each item has a price shown to customers:

<span class="item-price">$18/doz</span>

Change these to match.

Place 3 (if you want): There is no master price list on the site, so the prices only need to match within each event card and its corresponding order form checkbox group.

Quick find trick: Use your editor's "Find and Replace" feature (Ctrl+H or Cmd+H). Search for the old price like $18/dozen and replace with the new one. This catches most instances in one go.

How to Add Your Phone Number

The site has a placeholder phone number: (000) 000-0000. You need to replace it with your real number.

Here's how:

  1. Open index.html in your editor.
  2. Use Find and Replace (Ctrl+H or Cmd+H).
  3. In the "Find" box, type: (000) 000-0000
  4. In the "Replace" box, type your real number, like: (801) 555-1234
  5. Click "Replace All".

There's also a phone link you should update. Search for +10000000000 and replace it with your number in the format +18015551234 (no dashes or spaces, with the country code 1 in front).

<!-- Find this in the footer: -->
<a href="tel:+18015551234">(801) 555-1234</a>
The phone link is what makes the number clickable on mobile phones. The href="tel:..." part needs the number with no spaces or dashes, and the text between the tags is what people see on screen.

How to Add Your Photo

The About section currently shows a pretty gradient placeholder that says "Your photo here." Here's how to replace it with a real photo:

Step 1: Put your photo in the images folder (the same folder that has the bakery photos). Name it something simple like kathleen.jpg.

Step 2: Search for about-image in your file. You'll find this line:

<div class="about-image"></div>

Step 3: Replace it with:

<div class="about-image" style="background: url('images/kathleen.jpg') center/cover no-repeat;"></div>
Photo tips: A portrait-style photo works best here (the space is taller than it is wide). The photo will be cropped to fit, centering on the middle. If your face is getting cut off, you can change center to top in the style to focus on the top of the photo instead.
File name matters: Make sure the name in the code exactly matches your file name, including uppercase/lowercase. Kathleen.JPG is different from kathleen.jpg to a web browser.

How to Add Product Photos

In the "What We Make" section, some items already have photos and some show colored placeholders. Here's how to add a photo to any item.

Step 1: Put your product photo in the images folder. Name it something clear like cheese-rolls.png.

Step 2: Find the item in the code. Search for the item name (like "Cheese Rolls"). You'll see something like this:

<div class="showcase-icon bread"></div>

Step 3: Add has-image to the class and add the photo as a background image:

<div class="showcase-icon bread has-image" style="background-image: url('images/cheese-rolls.png')"></div>

Photo size: Square or slightly wide photos work best. They'll be automatically cropped to fit the card. Photos around 400x300 pixels are ideal — big enough to look sharp but small enough to load fast.

For sweets, use sweet instead of bread in the class. The only difference is the placeholder color (purple instead of pink), but the photo covers it either way:

How to Connect the Order Form

Right now, the order form looks beautiful but doesn't actually send the orders anywhere. To make it work, you'll use a free service called Formspree that sends form submissions to your email.

Step 1: Go to formspree.io and create a free account.

Step 2: Create a new form. Formspree will give you a form ID that looks something like xrgjeknl.

Step 3: In index.html, search for theForm. You'll find this line:

<form id="theForm">

Step 4: Change it to include the Formspree action and method:

<form id="theForm" action="https://formspree.io/f/xrgjeknl" method="POST">

(Replace xrgjeknl with your actual Formspree form ID.)

Step 5: You'll also want to update the JavaScript so it actually submits instead of just showing a success message. Search for e.preventDefault() near the bottom of the file and delete (or add // in front of) the entire block from document.getElementById('theForm').addEventListener through its closing });. Formspree will handle the submission and redirect.

Formspree's free plan gives you 50 submissions per month, which is perfect for a small bakery. When someone submits an order, you'll get an email with all their details — name, phone, event, items, and notes.
Alternative: If you'd rather get orders by text message, you can skip Formspree and just have people text you directly. Replace the order form with a simple message like "Text me at (your number) with your order!" Many cottage bakers prefer this personal touch.

How to Go Live

When you're happy with how everything looks, it's time to put your site on the internet. The easiest free way is Netlify Drop.

Here's all you do:

  1. Go to app.netlify.com/drop.
  2. Drag your entire project folder (the one containing index.html and the images folder) onto the page.
  3. That's it! Netlify gives you a live link you can share.

The free link will look something like random-name-12345.netlify.app. You can:

  • Create a free Netlify account to keep the site and pick a nicer name (like kathleens-kitchen.netlify.app).
  • Later, connect a custom domain (like kathleenskitchen.com) if you buy one — domains usually cost about $12/year from sites like Namecheap or Google Domains.
Updating your live site: Any time you make changes to your files, just drag the folder onto Netlify Drop again and it replaces the old version. Your link stays the same.
Make sure your folder includes everything: The folder you drag should contain both index.html and the images folder. If you only drag the HTML file, the photos won't show up.

You've Got This!

Updating a website can feel intimidating at first, but it really is just finding the right spot in the file and changing the words. The more you do it, the more natural it becomes.

A few golden rules to remember:

  • Always save a backup before making changes. Just copy the whole folder and name it something like "backup-march-6".
  • Test locally first. Double-click index.html to open it in your browser and see how it looks before going live.
  • Be careful with the angle brackets (< and >). Every opening tag needs a closing tag. If something looks broken, you probably accidentally deleted one.
  • Undo is your friend. If something goes wrong, Ctrl+Z (or Cmd+Z on Mac) takes you back.

Happy baking (and happy editing)!
